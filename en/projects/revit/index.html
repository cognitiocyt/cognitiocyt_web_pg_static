About the Project

We cannot solve our problems with the same thinking we used when we created them.

The process of drafting buildings in a 3D environment like Revit is laborious, tedious and expensive. There are certain tasks of the drafting process that deserve human intervention. However, most of the drafting process like the creation of panels, framing, positioning of various structural components, creation of shop drawings and more can me automated given a set of constraints. The present software automates the process of:

  • Panelizing walls, roofs and floors
  • Framing
  • Shop drawings creation

The scripts have been implemented as plugins in the Revit Enviroment.

Software Features

Optimized

Various algorithms and mathematical models have been created to ensure low latency and high accuracy.

Customizable

The software has been developed to be adaptable for different engineering constraints.

Scalable

The algorithims are implemented to run with one or many clients.

Documented

Every piece of code has been documented properly and hints for familiarization are given at all times.

Panelization

The panelization script is developed as a Revit plugin. Once a main component is selected, the script calculates the exact breaks and shapes needed to panalize them.

The script does not need any intervention other than an adjustment of the initial parameters.

Framming

Once all main components have been divided as panels or sections, a second scripts frames every panel. Every panel is assigned a set of constraints used to position the studs or framming components within the 3D model.

The insertion of all structural components is mathematically optimize based on the geometry and parameters in the existing project.

Shop Drawings

Ultimately, once the 3D model is complete then a script automatically verifies the accomplishment of the given engineering constraints and creates the manufacturing drawings of each panel.

The script is able to follow a template and place the necessary perspectives of each panel.
