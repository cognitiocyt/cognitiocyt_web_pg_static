Automatización del dibujo técnico con la API de Revit

Contáctanos

Acerca del proyecto

No podemos resolver nuestros problemas con el mismo pensamiento que usamos cuando los creamos.

El proceso de dibujar edificios en un entorno 3D como Revit es laborioso, tedioso y costoso. Algunas tareas del proceso requieren intervención humana; sin embargo, la mayor parte, como la creación de paneles, el entramado, el posicionamiento de diversos componentes estructurales y la creación de planos de taller, puede automatizarse a partir de un conjunto de restricciones. Este software automatiza el proceso de:

  • Panelización de muros, techos y pisos
  • Entramado
  • Creación de planos de taller

Los scripts se han implementado como complementos (plugins) en el entorno de Revit.

Características del software

Optimizado

Se han desarrollado diversos algoritmos y modelos matemáticos para garantizar baja latencia y alta precisión.

Personalizable

El software ha sido desarrollado para adaptarse a diferentes restricciones de ingeniería.

Escalable

Los algoritmos están implementados para funcionar con uno o varios clientes.

Documentado

Cada parte del código está debidamente documentada y se ofrecen indicaciones para familiarizarse con él en todo momento.

Panelización

El script de panelización está desarrollado como un complemento de Revit. Una vez seleccionado un componente principal, el script calcula los cortes y las formas exactas necesarias para panelizarlo.

El script no requiere ninguna intervención aparte del ajuste de los parámetros iniciales.

Entramado

Una vez que todos los componentes principales se han dividido en paneles o secciones, un segundo script genera el entramado de cada panel. A cada panel se le asigna un conjunto de restricciones que se utilizan para posicionar los montantes o componentes del entramado dentro del modelo 3D.

La inserción de todos los componentes estructurales se optimiza matemáticamente en función de la geometría y los parámetros del proyecto existente.

Planos de taller

Finalmente, una vez completo el modelo 3D, un script verifica automáticamente que se cumplan las restricciones de ingeniería y crea los planos de fabricación de cada panel.

El script puede seguir una plantilla y colocar las vistas necesarias de cada panel.
